# Hello Guide

这是 `.stem/tools/skill/` 兼容装载器的冒烟样例技能。正文要点：

1. 技能 = 一段"需要时才进入上下文"的操作指南，不是权限也不是能力开关。
2. 附属脚本放本目录（`<技能名>/scripts/…`），模型读完正文后经文件工具触达。
3. 若某技能高频使用，可让 LLM 把它升级为真工具（`.stem/tools/<名>/<名>.ts`，
   提示词逻辑内化进 execute）——系统对两条路都无特判。

验收口令：复述本技能的三个要点编号即可。
