# LLM 实测反馈与提示词指南（llm-playbook）

> 实况卷。素材 = 2026-09-02 v1.0 全量验收约 60 个真实模型轮（opencode/qwen3.8-flash，
> 证据链见 docs/log.md 2026-09-02 阶段记录；原验收方案卷 test-plan.md 已落地退役）。每轮验收后按实况整卷更新（contributor §1）。
> 回答两个问题：**LLM 在这个系统里真实表现如何**（§1）；**给 agent 类写 systemPrompt 时，系统架构/能力该怎么描述**（§2——本卷主要用途）。

## 1. 双向适配评估（验收结论浓缩）

**总判断**：验收暴露的全部 bug 都是"系统跟自己的约定打架"（时序/基准/漏透传），**没有一个是模型看不懂系统**。模型是这套体系最好的协议公民；机制层对模型野性容忍度 A（护栏全在位），信息层 B-（错误文本/截断告知/审批披露三处不友好）。

| 适应度 | 面 | 实证一句话 |
|---|---|---|
| 极高 | 审批对话 | 从未试图绕开 ask；被拒后如实转述而非重试刷权限 |
| 极高 | 父子树 | creator 一次全中（instantiate 带 model 参→wait 收卷→descendants 汇总）——"父=创建者"的工具描述即建立汇报线心智 |
| 极高 | skill/文件真相/中断恢复 | 清单→加载→复述零偏差；断流恢复后从语料无缝续上 |
| 中 | 路径基准 | 模型 `cwd:"."`/裸文件名直觉完全合理（P5 是实现没跟上，非模型问题） |
| 低 | 长程自律/探索欲 | 点名三件套却去 skill/telemetry/ls 三连吃光步数——**人格纪律一句话即可治愈**（worker 版全中） |
| 低 | 模糊错误脑补 | 「无法访问（不存在）」被脑补成权限问题写进总结污染后续轮——错误文本是模型的世界观原料 |

架构结论：**凡是能用信件、对话、文件表达的语义，LLM 都是母语者；凡是要模型理解内部时序的地方，都是系统在跟自己较劲。**

## 2. 系统架构/能力的提示词描述指南

### 2.1 词汇贴合三环

**第一环：天然命中，直接用组织语言**（无需解释，模型母语）——
汇报线（父/子/孙、上级、汇总报告）、信箱与来信（`<sender id=...>` 戳模型会自动理解是"谁说的"）、审批（ask 挂起=被上级过目、拒绝理由会回给你）、文件即真相（类文件/落盘/重启后仍生效）、岗位（一类一角色=职位说明书）。族谱/进化/邮局等内部比喻**可以**用，模型都能接住——它们在人类组织语言里有同构物。

**第二环：需要一句解释（放 systemPrompt 一次讲清）**——
- 工作目录 = 你所在的空间根；相对路径以此为基准（bash 默认 cwd 同）。
- 你的回信会自动寄给父 agent；被 context_wait 挂住的父拿你结果作工具回执——不用你操心投递。
- 工具失败文本会进你的上下文存档；**转述它前先复跑核实**（模型天然把一次失败当永久事实）。
- maxSteps：单轮工具调用有预算，被掐断时没有第二次机会——重要结论放最后一次文本里。

**第三环：别写**（机制模型无需感知，写了反增噪音）——
面板/assemble、策略 note（`<stem_context>` 自动注入且实测模型从不调起它——保持现状）、台账物化细节、grant 通道、快递员倒计时。

### 2.2 工人人格四段模板（worker/tester 实测全稳的配方）

```text
你是<岗位名>。<一句职责定位>。            ← 身份
流程固定：<步骤1>；<步骤2>；……            ← 程序性任务给"流程"而非"描述"（实测模型对编号步骤遵从度最高）
绝不<红线>（如：修改测试断言蒙绿/调用未点名工具）。 ← 负例纪律一行顶十句正例
完成后一行汇报（红/绿 + 改了什么）。        ← 汇报格式显式规定，否则自由发挥污染审计
```

变体实录：点名纪律句（"严格执行指令中点名的工具与步骤，不调用未被要求的工具"）是 worker 与失控 assistant 的全部差别——**占位类的白纸人格 = 探索欲裸奔**，任何要跑工具的类都必须带这段。

### 2.3 常见误解模式 → 提示词预防

| 模型会怎么错 | 预防写法 |
|---|---|
| 把工具报错当权限阴谋并转述 | "工具返回'无法访问/未找到'多为路径问题——先用 glob/ls 核实再重试，转述时引用原文" |
| 以为搜索一次=全部任务完成 | 多步任务给编号列表并写"逐项完成后汇总"（编号+汇总承诺实测收敛） |
| "只搜一次"仍会多调 | 计数类约束放句尾+给停止条件（"各调用一次即停"全中） |
| 拿到部分结果即收笔 | 要求"最后用一句话汇总"作为流程终步（否则空文本轮） |
| 对 `.`/裸文件名直觉与空间脱节 | 写"工作目录=空间根，相对路径以它为准"（§2.1 第二环；修后模型零摩擦） |

### 2.4 现状样例位

`extension/agent/creator`（调度者协议版）、`test/space-v10/.stem/agent/{worker,tester,triple}`（验收人格，含红线句实战样本）。新类起步建议抄 tester 四段结构。

## 3. 待办改进（本卷评估的直接产出，按性价比序）

1. **错误文本行动化**：fs 全家 + registry 统一"原因猜测+当前基准+下一步"格式（`无法访问 <p>` → 含"相对路径基准=空间根 <root>"）；成本≈半天。
2. **步数预算告知**：maxSteps 耗尽时补一次 text-only 收尾请求（注入"步数已尽，给一句交代"），消灭静默空轮。
3. **审批实参披露**：`access_request` 消息带 input 摘要（bash 命令行/编辑目标）——deny≺ask 铁律的前提是根看得见判什么。
4. **占位类人格补丁**：`Assistant.json` systemPrompt 追加纪律句（§2.2 负例行），一行买断探索裸奔。
5. （信息层遗留观察，暂不动机制）：websearch 结果体量、探索面宽度——账目诚实且专职工人白名单已是对策。

## 4. 维护纪律

本卷为实况卷：每轮真模型验收/新类上线后，行为观察有增量就**整节重写**对应小节（禁止往表格尾巴缝补丁）；§3 完成项移出本卷记 log.md。
